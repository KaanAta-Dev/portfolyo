# Portfolyo Sitesi

HTML, CSS ve JavaScript ile hazırladığım kişisel tanıtım sitem.

🔗 **Canlı site:** https://kaangt-r.github.io/portfolyo/

## Kullanılan teknolojiler

- HTML
- CSS (Flexbox, Grid, CSS değişkenleri, media query)
- JavaScript

## Özellikler

- Telefon, tablet ve bilgisayarda uyumlu görünüm
- Karanlık mod (seçim tarayıcıda hatırlanır)
- Telefonda açılır kapanır menü
